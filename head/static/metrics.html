Metrics

Insights stores metrics at one-minute resolution and serves them through a Prometheus-compatible API, one region at a time. Names are written with dots when you ask (do.droplets.cpu_utilization) and come back with underscores in the results. The chart below is a range query for the region you picked. Choose 'both' to see Toronto and Sydney side by side; Porthole asks each region separately because the API does not add regions together.
