What you're looking at

Porthole is a window onto DigitalOcean Insights. The kraken outside is a small fleet we run for this demo: three Droplets called tentacles (two in Toronto, one in Sydney), a load balancer, a managed Postgres, a one-node Kubernetes cluster, a Function, a Spaces bucket, a container registry and a Managed Agents session. You can make the fleet do things, then see what Insights records about it through the same API you would use. Every number on this page came from an Insights API call; the calls are listed in the drawer at the bottom.
